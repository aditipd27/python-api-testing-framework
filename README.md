# \# Python API Testing Framework

# 

# A Python-based API testing project using `pytest` and `requests` to validate REST API functionality.

# 

# \## Tech Stack

# 

# \- Python 3.11

# \- Pytest

# \- Requests

# \- REST APIs

# \- JSON

# 

# \## Test Coverage

# 

# The framework currently includes tests for:

# 

# \- GET user details

# \- GET all users

# \- Negative testing for non-existing users

# \- POST user creation

# \- HTTP status code validation

# \- JSON response validation
